CloudSOC — Normalized Relational Database ER Schema (11 Core Tables + Sessions)

Aligned across SQLite runtime (server/db.ts) and PostgreSQL migration (migrations/001_initial_postgresql.sql)

roles

  • PK id
  • UQ name (ADMIN | SECURITY_ANALYST)
  • description
  • created_at

users

  • PK id
  • UQ username, email
  • password_hash (bcrypt)
  • FK role_id → roles.id
  • is_active, failed_login_attempts
  • locked_until, last_login_at

security_events

  • PK id, UQ event_uid
  • timestamp (IDX)
  • source_ip (IDX), username
  • event_type (IDX), severity (IDX)
  • detection_status, rule_triggered

detection_rules

  • PK id, UQ rule_code
  • name, event_type_target
  • threshold, time_window_minutes
  • severity, is_enabled

alerts

  • PK id, UQ alert_uid
  • FK rule_id → detection_rules.id
  • FK trigger_event_id → security_events.id
  • FK assigned_to → users.id
  • severity, status, event_count
  • window_start, window_end

incidents

  • PK id, UQ incident_uid
  • FK alert_id → alerts.id
  • FK assigned_to → users.id
  • FK created_by → users.id
  • priority, status (NEW..RESOLVED)
  • resolution_summary, closed_at

incident_notes

  • PK id
  • FK incident_id → incidents.id
  • FK author_id → users.id
  • note, created_at

response_actions

  • PK id
  • FK incident_id → incidents.id
  • FK performed_by → users.id
  • action_type, action_details, status

threat_indicators

  • PK id
  • indicator_type, indicator_value
  • reputation_score, verdict, source
  • FK queried_by → users.id
  • cached_until

audit_logs

  • PK id
  • FK user_id → users.id
  • username, action, resource_type
  • resource_id, details, ip_address

system_settings

  • PK id, UQ setting_key
  • setting_value, description
  • FK updated_by → users.id
  • updated_at

sessions

  • PK id, UQ token_hash
  • FK user_id → users.id
  • csrf_token, expires_at
  • ip_address, user_agent
Key Foreign-Key Relationships (1:N): roles (1) ──▶ (N) users · detection_rules (1) ──▶ (N) alerts · security_events (1) ──▶ (N) alerts · alerts (1) ──▶ (0..N) incidents · incidents (1) ──▶ (N) incident_notes & response_actions · users (1) ──▶ (N) audit_logs, sessions, threat_indicators.
