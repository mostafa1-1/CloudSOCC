CloudSOC — Authentication, CSRF & RBAC Security Flow

Server-side credential verification, brute-force telemetry logging, HttpOnly cookies, and role enforcement

STEP 1

Credential Submit

User submits email/username & password over HTTPS POST /api/auth/login.

STEP 2

Lockout & bcrypt

Server checks active status & lockout timestamp, then compares bcrypt hash (cost 10).

STEP 3

Event & Detection

Failed or successful login writes to security_events (password redacted) and triggers RULE-001/002.

STEP 4

Session & CSRF

On success, SHA-256 hashed token stored in DB; HttpOnly + SameSite=Lax cookie + CSRF token issued.

STEP 5

RBAC Guard

Protected routes verify session + X-CSRF-Token; Admin routes reject SECURITY_ANALYST with HTTP 403.
